# CartaViva

Landing + primer MVP del builder para una carta digital visual con fotos, menú del día, productos agotados y QR.

## Páginas

- `/` Landing pública
- `/builder` Panel/builder guiado con localStorage
- `/demo` Carta pública demo
- `/carta/casa-amelia` Carta pública simulada usando localStorage

## Cómo desplegar sin terminal local

1. Descomprime el ZIP.
2. Sube el contenido de la carpeta a un repositorio de GitHub.
3. Importa el repositorio en Vercel.
4. Vercel ejecutará la instalación y el build automáticamente.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS 3.4.17
- lucide-react
- framer-motion

## Nota

El builder guarda los datos en localStorage. Todavía no incluye login, base de datos, pagos ni QR real descargable.
