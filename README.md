# CartaViva

Landing inicial para CartaViva: carta digital visual para restaurantes con fotos, menú del día, idiomas y QR.

## Cómo ejecutarlo

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Subir a GitHub

```bash
git init
git add .
git commit -m "Primera landing CartaViva"
git branch -M main
git remote add origin https://github.com/TU-USUARIO/cartaviva.git
git push -u origin main
```

## Desplegar en Vercel

Importa el repositorio desde Vercel y selecciona Next.js.
